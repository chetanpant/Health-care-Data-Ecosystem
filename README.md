## About

This is an interactive learning experience built as a companion to a course on healthcare data fundamentals. Instead of teaching abstract concepts through dense slides, the entire experience is told through the story of **Anjali Sharma** — a 47-year-old patient from Bangalore whose journey reveals how healthcare data actually works.

The goal: turn complex ideas into **clicks**, not paragraphs.

## What it covers

The guide walks through four core areas of healthcare data, mapped to Anjali's real medical record:

- **The Opening Scene** — A 5-scene click-through narrative about why healthcare data so often fails patients
- **Types of Data** — Structured, unstructured, and semi-structured, with tappable examples from Anjali's chart
- **Characteristics** — Longitudinal, high-dimensional, heterogeneous, and sensitive (each with its own mini-interaction)
- **Standards** — ICD, CPT, LOINC, SNOMED CT, and HL7/FHIR — every code on Anjali's chart is decodable with a tap
- **Knowledge Check** — A 5-question quiz with feedback grounded in Anjali's case

## How to use it

Just open the live link on any device — phone, tablet, or laptop. The experience is designed mobile-first and takes about 5–7 minutes end to end. Tap, swipe, drag, and click your way through.

## What's under the hood

- **Pure HTML, CSS, and JavaScript** — no frameworks, no build steps, no dependencies (apart from Google Fonts)
- **A single `index.html` file** — drop-in deployable on any static host
- **Editorial design** — Fraunces + Instrument Serif for display, DM Sans for body, JetBrains Mono for code
- **Real interactions** — swipeable carousels, tap-to-expand cards, an animated patient timeline, code decoders, a click-through narrative, and a quiz
- **Mobile-first and fully responsive**
